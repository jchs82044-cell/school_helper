# 학교생활 도우미

학교 시간표와 급식 메뉴를 한곳에서 확인하고, 학교 일정을 잊지 않도록 알려 주는 웹 앱입니다.

## 목표 사용자와 문제

- 학교 시간표와 급식 메뉴를 따로따로 찾지 않고 동시에 확인하고 싶은 학생
- 학교 일정을 잘 까먹어서, 미리 상기시켜 주길 원하는 학생

## 핵심 기능

1. **학년 입력**: 사이트에 들어가 자신의 학년을 입력합니다.
2. **시간표**: 학년 입력 후 시간표 프레임이 나타나고, 학생이 직접 시간표를 입력하거나 수정할 수 있습니다.
3. **급식 카탈로그**: 별도의 급식 카탈로그를 클릭하면 기간을 조절해 학교의 중식·석식 메뉴를 확인할 수 있습니다.
4. **일정 알림**: 학교 일정을 상기시켜 주어 잊지 않고 학교생활을 즐길 수 있게 합니다.

## 확정된 결정

- **학교**: 세종특별자치시 종촌고등학교 (고정, 코드 B000023140)
- **급식 데이터**: 참고 사이트(school.koreacharts.com)는 CORS 미허용이라 브라우저에서 직접 가져올 수 없어, 같은 공공데이터인 NEIS 교육정보 개방포털 API를 사용합니다.
- **알림**: 일정 당일 아침에만 알림(접속/열어둔 때 화면 배너 + 브라우저 알림 권한 허용 시 알림)

## 제약 사항

- 설치나 빌드 없이 `index.html` 파일만 열면 동작해야 합니다.
- GitHub 웹(GitHub Pages)에 업로드하여 공개합니다.

## 만드는 순서 (계획)

1. `index.html` 단일 파일 뼈대 만들기 (HTML/CSS/JS 인라인)
2. 학년 입력 화면 및 저장(localStorage)
3. 시간표 프레임 표시, 입력·수정·저장 기능
4. 급식 카탈로그 화면: 기간 선택 + 중식/석식 표시
5. 일정 등록 및 알림(상기) 기능
6. 모바일 대응 및 화면 다듬기
7. 동작 확인 후 GitHub Pages 배포 안내
